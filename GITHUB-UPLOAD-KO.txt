GitHub 업로드
1. ZIP 압축을 먼저 풀어 주세요. ZIP 파일 자체를 올리면 소스가 펼쳐지지 않습니다.
2. GitHub Desktop에서 빈 저장소를 Clone한 후 압축을 푼 파일을 저장소 폴더에 복사하세요.
3. package.json과 app, lib, public 폴더가 저장소 최상위에 있도록 하세요.
4. Commit 후 Push origin을 누르세요.
기존 저장소라면 기존 내용을 백업하고 변경 파일을 확인한 뒤 커밋하세요.

실행 환경
이 프로젝트는 Vinext/Cloudflare Workers 및 D1 데이터베이스를 사용합니다.
GitHub 업로드는 소스 보관이며, GitHub Pages에서 바로 게임을 실행할 수는 없습니다.
다른 호스팅으로 옮길 때는 서버 API와 D1 바인딩 DB 및 drizzle 마이그레이션 설정이 필요합니다.
현재 운영 중인 게임방·참가자·답안 데이터는 ZIP에 포함되어 있지 않습니다.
설치 및 실행 안내는 README.md를 참고하세요.
