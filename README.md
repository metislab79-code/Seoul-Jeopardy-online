# 서울 제퍼디 LIVE

해치와 함께하는 1~10조 온라인 서울 퀴즈쇼.

진행자가 방을 개설하고 참가자는 QR/입장코드, 조, 이름으로 입장합니다. 25문항 중 문제를 고르면 50초 동안 각 참가자가 한 번 답할 수 있습니다. 정답은 즉시 개인 화면에 표시되며 정답 공개 후 순위가 반영됩니다. 조 점수는 조원 평균입니다. 진행자는 공개된 답안을 재채점하고 결과를 CSV로 내려받을 수 있습니다.

참가자와 진행자 재접속 권한은 같은 브라우저에 저장되므로 방 링크를 보관하고 브라우저 데이터를 유지하세요. 게임 중에도 같은 QR코드로 신규 입장이 가능합니다. 늦게 참가하면 현재 문제의 남은 시간에 맞춰 연결되며, 끝난 문제에는 소급 응답할 수 없습니다. 게임 종료 후 신규 입장은 마감됩니다.

문제 원본: 사용자 제공 제퍼디쇼- 문제.xlsx의 Sheet1. 캐릭터: 사용자 제공 해치와 소울프렌즈. 서울 야경 배너: AI 생성 이미지.

서버: Cloudflare Worker / D1, 프런트: React / Vinext. 상태 갱신 주기 1.5초.

문제별 글자 수·초성 힌트가 문제 공개와 함께 표시됩니다. 대표 정답의 공백·문장부호를 제외한 글자 수이며, 영문 약자는 한글 발음을 기준으로 합니다. 서버 채점은 사전에 등록한 동의어·약칭·영문/한글 표기 및 축제/페스티벌 표기를 인정합니다. 기존 제출 답안은 자동 재채점하지 않으며 진행자가 정답 공개 후 수정할 수 있습니다.
